# 🌾 Crop Yield Prediction Model

An interactive Machine Learning web application that predicts crop yield based on regional agricultural indicators, soil/fertilizer features, and environmental data.

## 🚀 Live Application
Try the live interactive app here:  
👉 **[Hugging Face Space Live App](https://huggingface.co/spaces/tigabu-data-scientist/yeild_predection?v=1)**

## 🛠️ Project Structure & Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **ML Libraries:** Scikit-Learn, Pandas, NumPy, Category Encoders
* **Deployment:** Hugging Face Spaces & Docker
